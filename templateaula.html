Grammar

Second Conditional — hypothetical situations

If + past simple, ... would + base verb

Use this structure to talk about imaginary, unlikely, or hypothetical situations in a negotiation — things that aren't happening now, but could.

Example: "If the client asked for a discount, we would review the contract terms."
